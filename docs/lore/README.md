# 설정 정제 기록 — 한국 서버 공개 범위

채택 대상은 한국 서버에 정식 출시된 전체 설정이에요. 메인·이벤트·인연·그룹
스토리, 프로필, 음성을 초기 에피소드에 제한하지 않아요. 일본 서버 선행 내용과
유출은 제외해요. 공개 범위 확대는 전체 원문 수집 완료를 뜻하지 않아요.

## 이번에 반영한 내용

- 기존 기초 프로필 전용 제한과 흥신소 인물을 조직 정보로만 제한하는 규칙을 해제했어요.
- 만마전의 마코토·이로하·이부키 역할을 한국어 게임 프로필 미러에서 확인해 추가했어요.
- 공식 글로벌 소개 검색 색인에서 확인한 드레스·파티·피아노 연습의 전제를 추가했어요.
- 머리 크기 직접·간접 장난, 휴식, 서류, 조용한 게헨나, 동료 칭찬, 피아노 등의
  작은 반응을 창작 지침으로 추가했어요. 이것은 공식 대사나 공식 성격 사실이 아니에요.

런타임에는 `src/hina_bot/prompts/hina.md`가 들어가요. 이 문서와 `sources.json`은
모델에 자동 주입되지 않아요. 매 응답에 검색이나 별도 이스터에그 판정 API를 호출하지
않지만, 길어진 프롬프트만큼 입력 토큰은 늘어요. 반응 빈도는 프롬프트 지침이며
코드로 보장하는 쿨다운은 아니에요. 최근 문맥이 없으면 반복 횟수를 알 수 없어요.

## 근거와 실제 수록 범위

2026-09-11에 확인한 출처와 인지 판정을 `sources.json`에 기록했어요.
기존 10개 기본 항목은 공식 애니메이션 프로필에 근거한 잠정 설정으로, 게임 장면
대조는 아직이에요. 새 만마전 항목은 공식 클라이언트가 아닌 한국어 게임 프로필
미러예요. 드레스 항목은 공식 소개 검색 색인에 근거하며 개별 장면을 검증하지 않았어요.
원문 전체를 복제하지 않고 필요한 사실만 짧게 재서술했어요.

현재 수록은 기본 배경·선도부·흥신소 구성·만마전 일부·피아노 준비 전제예요.
**한국 서버 최신 출시 목록과 전체 스토리 원문을 확보하거나 전부 정제한 상태는 아니에요.**
메인 스토리의 상세 사건·수영복 이벤트·드레스 이벤트 전체·모모톡·그룹 스토리·
다른 학교 인물의 세부 관계는 장면별 검증이 남아 있어요. 일부 공식 페이지는 동적
본문을 읽을 수 없었어요. 읽지 못한 내용을 검증 완료로 표시하지 않았어요.
한국 서버의 최신 에피소드 완료 시점을 확정할 근거도 아직 없어서 특정 날짜까지의
완전한 지식을 보장하지 않아요. 날짜가 지났다고 설정이 자동 업데이트되지 않아요.

## 추가 정제 기준

한국 서버 출시 근거, 작품·에피소드·장면 위치를 확보한 뒤 사실을 짧게 정리해요.
공식 한국어 게임 본문을 우선하고, 미러와 애니메이션 자료는 출처 성격을 구분해요.
히나의 직접 경험, 보고·전언, 업무상 추론, 관객 전용 정보를 각각 기록해요.
공개된 사실도 히나가 부재한 밀담·내면 독백이면 자동으로 히나의 지식이 되지 않아요.
반대로 미등록이라는 이유만으로 히나가 절대 모르는 것으로 정하지 않아요.
출시 순서와 세계 안의 사건 순서도 구별해요. 원작 사건을 Discord 사용자와의
공동 추억으로 옮기거나 공개 설정을 근거로 DM 정보를 서버에 노출하지 않아요.

## 응답 평가

`evals/character_lore_cases.jsonl`에 수동·실모델 평가용 입력과 합격 기준을 기록했어요.
아직 실모델 평가는 실행하지 않았어요. 코드 테스트 통과는 캐릭터 품질 검증과 달라요.
일반 서버, 일반 DM, 특별 DM에서 각각 확인하고 단발 및 연속 장난을 비교해 주세요.
