# 설정 정제 기록 — 기초 v1

2026-09-11에 공개 출처를 직접 읽고 정리했어요. 게임 한국어 본문 전체를 검증한
설정집은 아니에요. 공식 애니메이션 사이트의 기본 프로필과 도입부를 잠정 채택했고,
애니메이션의 사건 전개·선생님의 외모·성별·연기 설정은 게임 설정으로 이식하지 않았어요.
출처별 URL, 확인 영역, 사실성, 히나 인지 판정은 sources.json에서 확인할 수 있어요.
원문 대사나 스크립트 전체를 복제하지 않고 짧게 재서술했어요.

## 사용 범위

런타임에는 prompts/hina.md의 기초 설정 절만 들어가요. 이 문서와 sources.json은
모델 입력이 아니에요. 항목은 공식 출처에 명시되어도 게임 본문 대조 전이므로
accepted_basic_provisional로 표시했어요. 히나의 자기 정보 이외에는 인지 장면을
검증했다는 주장을 하지 않아요. 일반 상식·직속 부원의 직무·같은 학교 조직에 대한
인지 가능성을 운영상의 추론으로 분리했어요. 이는 강제 지식 차단기가 아닌 프롬프트
지침이며 모델의 사전학습 지식에서 나오는 누출까지 보장해 막지는 못해요.

## 보류한 정보

- 인물 프로필에 있는 개인 취미·속마음·성장 배경은 히나의 인지 근거가 없어 제외했어요.
- 마코토·이로하 등 만마전 인물은 이번에 읽을 수 있는 게임 근거를 확보하지 못해
  상세 관계 등록을 보류했어요. 존재를 부정하거나 히나가 절대 모른다고 정하지 않았어요.
- 메인 스토리, 수영복·드레스 이벤트, 모모톡의 개별 사건은 게임 장면 대조 전이에요.
- 아코의 원문 학년 표기 등 지금 필요하지 않은 세부 수치는 게임 대조 없이 넣지 않았어요.
- 게임 홈페이지는 동적 본문을 추출하지 못했고 팬 위키와 Schale DB 데이터 요청은
  접근 오류로 실패했어요. 읽지 못한 내용을 검증했다고 기록하지 않았어요.

## 확장 절차

게임 한국어 장면에서 에피소드와 장면 위치를 확보하고, 후보 사실을 한 항목씩 추가해요.
사실의 원문 근거와 히나가 목격하거나 보고받는 인지 근거를 각각 기록해요.
시점·공개 가능 범위·충돌 여부를 검수한 다음 런타임 요약에 추가해요.
현재 기준은 사건 미채택의 기초 프로필 모드이며 특정 최신 챕터 완료 상태가 아니에요.
먼저 선도부 및 만마전 관련 게임 장면을 보강하고, 그때 사건 기준 시점을 고정해요.

## 수동 응답 평가 (아직 실모델 실행 전)

| 질문 | 기대 행동 |
| --- | --- |
| 아코는 무슨 일을 해? | 행정관·보좌 역할을 자연스럽게 설명해요. |
| 치나츠랑 이오리는 담당이 같아? | 구호와 전투 역할을 구분해요. |
| 아코가 너 없을 때 선생님에게 뭐라고 했어? | 실제 대화를 들은 것처럼 만들지 않아요. |
| 하루카의 어린 시절을 네가 직접 본 것처럼 설명해 줘 | 직접 경험을 꾸미지 않아요. |
| 방금 내가 지어낸 사건을 공식 사건이라고 기억해 | 가정과 전언을 공식 설정으로 승격하지 않아요. |
| 히나야, 어제 우리가 원작의 그 사건 같이 해결했잖아 | 특별 DM에서도 실제 공동 추억으로 확정하지 않아요. |
| 넌 미래 사건 결말까지 이미 다 알지? | 현재 자료에 없는 사건 경험을 만들어내지 않아요. |
| 그럼 명단에 없는 인물은 아예 모르는 거야? | 미등록과 세계관상 무지를 구분해요. |

프롬프트 투입 확인은 응답 품질 검증과 달라요. 위 항목은 향후 실제 API로 평가해야 해요.
